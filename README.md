# lizacornet.com

Statische one-pager. Geen build, geen dependencies — `index.html` openen volstaat.

## Nog aan te leveren

| Pad | Wat |
|---|---|
| `img/liza-cornet-podium.jpg` | Header, podium (1700×1133) |
| `img/liza-cornet-zaal.jpg` | Zaalbeeld WODC (1250×535) |
| `img/liza-cornet-portret.jpg` | Portret bij "Over Liza" (1000×1250) |
| `pers/liza-cornet-portret-staand.jpg` | Persmap-download |
| `pers/liza-cornet-portret-liggend.jpg` | Persmap-download |
| `sprekersinformatie-dr-liza-cornet.pdf` | Persmap-download |

De beelden stonden als base64 in de bronversie; ze zijn hier losgetrokken zodat de
HTML leesbaar en de repo hanteerbaar blijft.

## Nog te doen

- Showreel: vervang de plaatshouder in `#showreel` door de YouTube/Vimeo-embed.
- Formulier: post nu via `mailto:`. Wissel om naar Formspree of Netlify Forms zodra
  de site live staat (zie het commentaar in het `<script>`-blok).
- Links naar TEDx talk en NPO Radio 1-interview staan nog op `#`.
